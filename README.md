Sleep Health and Lifestyle -- Exploratory Data Analysis (EDA)

Project Overview

This project performs Exploratory Data Analysis (EDA) on the Sleep Health and Lifestyle dataset using Python. The purpose is to understand the dataset, identify patterns in sleep duration and sleep quality, explore relationships between lifestyle and health variables, and
prepare the data for further analysis or machine learning.

Objectives

- Understand the structure and quality of the dataset.
- Identify missing values and duplicate records.
- Summarize numerical and categorical variables.
- Explore sleep duration, sleep quality, and sleep disorders.
- Examine relationships between sleep and lifestyle factors.
- Visualize important patterns and possible outliers.
- Prepare a clean dataset for future analysis.

Dataset

file name: Sleep_health_and_lifestyle_dataset.csv

The dataset commonly contains fields such as: - Person ID - Gender -
Age - Occupation - Sleep Duration - Quality of Sleep - Physical Activity
Level - Stress Level - BMI Category - Blood Pressure - Heart Rate -
Daily Steps - Sleep Disorder
